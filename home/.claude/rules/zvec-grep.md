# zvec-grep (zg) workspace search

opencode on this machine has the `zvec_grep` MCP (`zg`). When its tools are listed: `zvec_grep_zvec_grep_rg` for a known word, identifier, path, config key, error string or regex; `zvec_grep_zvec_grep_search` when wording or location is unknown or the answer needs semantic, cross-file, chronological or causal synthesis (mixed tasks: `search` with the concept plus anchors, then `rg` for follow-up). Treat a sufficient result snippet as read evidence and open the file only for details outside it. Pass a daemon-visible absolute `root` on every call; results marked `served_from_current_index` are usable without waiting for the background refresh. Never create, rebuild or drop a persistent index without an explicit request. Without those tools, use `rg`/Grep.
